== II. Introduction ==

Create a brain computer interface based on electroencephalographic data
(EEG data) with the help of machine learning algorithms.
Using a subject's EEG reading, infer what he or she is thinking about or
doing - (motion) A or B - in a t0 to tn timeframe.


== III. Goals ==

- Process EEG data (parsing and filtering)
- Implement a dimensionality reduction algorithm
- Use the pipeline object from scikit-learn
- Classify a data stream in "real time"


== IV. General instructions ==

- Process data coming from cerebral activity with machine learning algorithms.
- The data was measured during a motor imagery experiment: people had to do
  or imagine a hand or feet movement, corresponding to a symbol displayed on
  screen. The result is cerebral signals with labels indicating the moments
  where the subject had to perform a certain task.
- Code in Python: MNE (EEG data processing) and scikit-learn (machine learning).
- The focus is implementing the dimensionality reduction algorithm, to further
  transform filtered data before classification. It must be integrated within
  sklearn so that sklearn tools can be used for classification and score
  validation.


== V. Mandatory part ==

Write a python program implementing three phases of data processing.

--- V.1.1 Preprocessing, parsing and formatting ---
- Parse and explore EEG data with MNE, from physionet.
- Write a script to visualize raw data, then filter it to keep only useful
  frequency bands, and visualize again after this preprocessing.
- Decide which features to extract from the signals to feed the algorithm
  (be thorough in picking what matters for the desired output).
  Example: use the power of the signal by frequency and by channel as the
  pipeline's input.
- Most filtering / spectrum algorithms use Fourier transform or wavelet
  transform (cf. bonus).

--- V.1.2 Treatment pipeline ---
Set up the processing pipeline:
- Dimensionality reduction algorithm (e.g. PCA, ICA, CSP, CSSP...).
- Classification algorithm: any among those available in sklearn, to output
  the decision of what data chunk corresponds to what kind of motion.
- "Playback" reading on the file to simulate a data stream.

It is advised to first test the program architecture with sklearn and MNE
algorithms, before implementing your own CSP (or whatever algorithm you chose).

- The program must contain a script for training and a script for prediction.
- The prediction script must work on a stream of data and output before a
  delay of 2s after the data chunk was sent to the processing pipeline.
  (Do not use mne-realtime.)
- You have to use the pipeline object from sklearn
  (use the BaseEstimator and TransformerMixin classes of sklearn).

--- V.1.3 Implementation ---
The aim is to implement the dimensionality reduction algorithm: express the
data with the most meaningful features by determining a projection matrix.
This matrix projects the data on a new set of axes that express the most
"important" variations (a change of basis: rotations, translations and
scaling).
- PCA considers the dataset and determines new basis components, sorted by
  how much those axes account for variations in the data.
- CSP (common spatial patterns) analyses the data depending on the output
  classes and tries to maximize the variations between them.
  PCA is more general, but CSP is more used in EEG BCIs.

Formal expression of an EEG signal:
    {E_n} for n = 1..N, E_n in R^(ch*time)
  - N    : number of events of every class
  - ch   : number of channels (electrodes)
  - time : length of the event recording
Extracted signal matrix X in R^(d*N), where d = ch*time is the dimension of a
signal vector for an event record.

Objective: find a transformation matrix W such that
    W^T X = X_CSP
where X_CSP is the data transformed by the CSP algorithm
(or X_PCA, X_ICA, ... depending on your choice).

Numpy or scipy functions are allowed to find eigenvalues, singular values, and
covariance matrix estimation.

--- V.1.4 Train, Validation and Test ---
- Use cross_val_score on the whole processing pipeline to evaluate your
  classification.
- Choose how to split the data set between Train, Validation and Test
  (do not overfit with different splits each time).
- You must have 60% mean accuracy on all subjects used in your Test Data
  (corresponding to the six types of experiment runs, on never-learned data).
- You can train / predict on the subject and the task of your choice.

Examples:

要約：脳波データにもとづく、機械学習を使った脳コンピュータインターフェース。


== II. はじめに ==

脳波（EEG：頭に電極をつけて測る脳の電気信号）のデータを使い、機械学習で
「脳とコンピュータをつなぐ装置（BCI）」を作る課題。
ある人の脳波を読み取って、その人が「動作 A をしている（想像している）のか、
動作 B なのか」を、t0 から tn の時間の範囲で当てる。


== III. 目標 ==

- 脳波データを処理する（読み込みとフィルタ）
- 次元削減のアルゴリズムを実装する
  [次元削減：たくさんある数値の中から、大事な情報だけを少ない数に
   まとめ直すこと]
- scikit-learn の pipeline（処理を順番につなぐ道具）を使う
- 流れてくるデータを「リアルタイム」で分類する


== IV. 一般的な指示 ==

- 脳の活動のデータを、機械学習のアルゴリズムで処理する。
- データは「運動イメージ」の実験で測ったもの。被験者は、画面に出た記号に
  合わせて、手または足を動かす（または動かすのを想像する）。結果として、
  「どの時刻に、どの動作をしたか」のラベルがついた脳波が得られる。
- Python で書く。脳波の処理に強い MNE と、機械学習の scikit-learn が使える
  から。
- この課題の中心は、次元削減のアルゴリズムを自分で実装すること。フィルタを
  かけたデータを、分類の前にさらに変換する。そのアルゴリズムは sklearn に
  組み込める形にして、sklearn の分類や点数の確認の道具を使えるようにする。


== V. 必須の部分 ==

データ処理の3つの段階を実装した Python プログラムを書く。

--- V.1.1 前処理・読み込み・整形 ---
- physionet（公開されている脳波データ）の脳波を、MNE で読み込んで調べる。
- 生のデータを図にするスクリプトを書く。次に、役に立つ周波数帯だけが
  残るようにフィルタをかけ、フィルタ後のデータをもう一度図にする。
- この段階で、信号からどんな特徴（特徴量）を取り出してアルゴリズムに
  渡すかを決める。出したい答えに本当に関係するものを、よく考えて選ぶ。
  例：周波数ごと・電極ごとの信号の強さ（パワー）を、パイプラインへの
  入力にする。
- フィルタや周波数の分析のアルゴリズムの多くは、フーリエ変換かウェーブレット
  変換を使う（ボーナス参照）。
  [フーリエ変換：信号を「どの周波数がどれだけ入っているか」に分けて見る
   方法]

--- V.1.2 処理のパイプライン ---
処理のパイプラインを作る：
- 次元削減のアルゴリズム（例：PCA、ICA、CSP、CSSP…）
- 分類のアルゴリズム。sklearn にあるものから好きに選べる。データのどの
  かたまりが、どの動作に当たるかを出力する。
- ファイルを「再生」して読む処理（データが流れてくる状況のまねをする）

自分で CSP などを実装する前に、まず sklearn と MNE のアルゴリズムで
プログラム全体の作りを試すことをすすめる。

- 学習用のスクリプトと、予測用のスクリプトを用意する。
- 予測のスクリプトは、データの流れを相手に、データのかたまりを
  パイプラインに送ってから 2 秒以内に結果を出す。
  （mne-realtime は使わない）
- sklearn の pipeline を使う。（sklearn の BaseEstimator と
  TransformerMixin のクラスを使うこと）

--- V.1.3 実装 ---
目的は、次元削減のアルゴリズムの実装。つまり、データを一番意味のある特徴で
表し直すために、「射影行列」を求めること。この行列は、データを新しい軸の
組に投影して、一番「重要な」変動が目立つようにする。これは基底変換と呼ばれ、
回転・平行移動・拡大縮小でできている。
- PCA（主成分分析）は、データを見て新しい軸を決める。軸は、データの
  ばらつきをどれだけ説明するかの順に並ぶ。
- CSP（共通空間パターン）は、出力のクラス（動作 A か B か）ごとにデータを
  分析して、クラス同士のばらつきの差が一番大きくなるようにする。
  PCA はもっと一般的なアルゴリズムだが、脳波の BCI では CSP のほうがよく
  使われる。

脳波信号の形式的な表し方：
    {E_n}（n = 1..N）は、R^(ch*time) の要素
  - N    ：各クラスのイベント（試行）の数
  - ch   ：チャンネル（電極）の数
  - time ：1つのイベントの記録の長さ
取り出した信号の行列 X は R^(d*N) の要素。d = ch*time は、1つのイベントを
並べたベクトルの次元。

目標は、次の式を満たす変換行列 W を見つけること：
    W^T X = X_CSP
X_CSP は、CSP で変換したあとのデータ（選んだ手法によっては X_PCA や
X_ICA など）。

固有値・特異値・共分散行列の推定には、Numpy や scipy の関数を使ってよい。
[固有値・特異値：行列が、どの向きにどれだけ引き伸ばすかを表す数。
 共分散行列：データ同士がどれだけ一緒に動くかをまとめた表]

--- V.1.4 学習・検証・テスト ---
- 処理全体のパイプラインに対して cross_val_score を使い、分類の成績を
  評価する。
  [cross_val_score：データを分けて、学習と評価を何回も繰り返し、点数を出す
   sklearn の関数]
- データを学習・検証・テストにどう分けるかは自分で決める。（毎回違う分け方に
  して、過学習しないこと）
- テストデータに使った全被験者で、平均 60% の正解率が必要。（6種類の実験の
  run と、学習したことのないデータで）
- どの被験者・どの課題で学習・予測してもよい。

例（上の英語のとおり）：
- `python mybci.py 4 14 train`：被験者4・run 14 で学習。10分割の点数と
  cross_val_score の平均（例では 0.5333）を出す。
- `python mybci.py 4 14 predict`：エポック（データのかたまり）ごとに
  [予測] [正解] [一致したか] を出し、最後に正解率（例では 0.6666）を出す。
- `python mybci.py`（引数なし）：全被験者（109人）について、6種類の実験
  それぞれの正解率と、6種類の平均（例では 0.6261）を出す。


== VI. ボーナス ==

ボーナスは、課題のどの段階の改善でもよい。例：
- 信号のスペクトル（周波数ごとの強さ）の変化を調べて、前処理を改善する。
  （例：ウェーブレット変換を使う）
- 自分の分類器、またはパイプラインのほかの段階を自分で実装する。
- ほかのデータセットで試す。

パイプラインのほかの部分を実装すると、読み込み・前処理・分類を深く掘り下げる
ことになる。さらに難しいボーナスは、固有値・特異値分解や共分散行列の推定の
関数を自分で書くこと。（データにノイズがあり、正方行列にならないので難しい）
