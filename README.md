# total-perspective-vortex

42 の課題：脳コンピュータインターフェース（BCI）。運動イメージの脳波（EEG）から、
手を動かしているのか足なのかを、MNE と scikit-learn で当てる。

## ファイルの置き場所

| パス | 中身 |
|---|---|
| `mybci.py` | 入口（`train`、`predict`、引数なしで全被験者の評価） |
| `src/visualize.py` | 生の脳波とフィルタ後の脳波の図 |
| `src/tpv/data.py` | physionet のデータを MNE で読み込む |
| `src/tpv/preprocessing.py` | フィルタと特徴の取り出し |
| `src/tpv/csp.py` | 自分で書く次元削減（sklearn の transformer） |
| `src/tpv/pipeline.py` | sklearn の `Pipeline` |
| `src/tpv/stream.py` | 録画を流れるデータとして再生する |

## 使い方

```
make install
make visualize SUBJECT=4 RUN=14
make train SUBJECT=4 RUN=14
make predict SUBJECT=4 RUN=14
make eval
```

`make help` で一覧が出る。

## データ（PhysioNet EEG Motor Movement/Imagery）

`src/tpv/data.py` の `eegbci.load_data(subject, runs)`：

- `subject: int`：被験者。1〜109。
- `runs: list[int]`：記録1回分（run）の番号。1〜14。EDF ファイルのパスのリストを返す。

1人の被験者が 14 回記録している。最初の2回は1分のベースライン、そのあとは
2分のタスク4種類を3回ずつ。

| run | 課題 |
|---|---|
| 1 | ベースライン（目を開けて休む） |
| 2 | ベースライン（目を閉じて休む） |
| 3, 7, 11 | 左拳か右拳を動かす |
| 4, 8, 12 | 左拳か右拳を動かすのを想像する |
| 5, 9, 13 | 両拳か両足を動かす |
| 6, 10, 14 | 両拳か両足を動かすのを想像する |

イベントの印（アノテーション）の意味は run の種類で変わるので、run の番号を見て
ラベルに直す。

| 印 | run 3, 4, 7, 8, 11, 12 | run 5, 6, 9, 10, 13, 14 |
|---|---|---|
| T0 | 休み | 休み |
| T1 | 左拳 | 両拳 |
| T2 | 右拳 | 両足 |

課題は「手か足か」なので、使う run は 5, 6, 9, 10, 13, 14（想像のほうは 6, 10, 14）。
サンプリング周波数 160 Hz、64 チャンネル。

run の構成とイベントの印の意味は PhysioNet のページで確認した。run と課題の対応表は
記憶で書いた。使う前に PhysioNet / MNE のドキュメントで確かめること。

### 各 PDF の要点

#### BCI入門チュートリアル_Bonci2021.pdf（3.4 節 ERD/ERS、2.4 節 前処理）

- 運動イメージ BCI（MI-BCI）は、手・足・舌などを動かす想像で運動野の活動が変わることを使う。
  想像する部位によって、変化が出る脳の場所が違う（左手と右手で別の場所）。
- 運動イメージをすると、運動野付近の電極で mu 波（8〜15 Hz）と beta 波（10〜30 Hz）のエネルギーが
  下がる。下がるのが ERD、上がるのが ERS。
- ERD = (P_event − P_ref) / P_ref。P_event は合図のあとの帯域パワー、P_ref はその前の基準期間のパワー。
- 図 11 の例：8〜30 Hz のバンドパスをかけて、左手・右手の想像を100試行平均すると、電極 CP3 / CP4 で
  パワーの低下がはっきり見える。
- CSP：多チャンネル脳波の各チャンネルに重みをかけ、2つの課題で出力の分散が最も違うようにする空間フィルタ。
  2つの共分散行列 C1, C2 の一般化固有値問題 `C1 w = λ C2 w` で求める。λ が最大の w が課題1用、最小の w が課題2用。
- CSP は周波数帯と強く関係する。mu / beta 帯の幅と中心周波数は人によって違うので、帯域を選ぶ派生手法
  （FBCSP など）がある。共分散行列の推定の質が、そのまま分類精度に響く。
- CSP は2クラス向け。多クラスへの拡張や、共分散行列をそのまま分類するリーマン幾何の方法もある。
- 前処理：自発脳波は FIR バンドパスフィルタや FFT で取り出す。目のまばたきや筋肉のアーチファクトは
  回帰や ICA で取る。分類器には LDA や SVM がよく使われる。

#### BMI講義スライド_ATR山下.pdf（運動出力型 BMI の部分）

- BMI は、脳信号の読み取りや脳への刺激で、脳と機械をつなぐ仕組みの総称。入力型（人工内耳など）と
  出力型（ロボットやコンピュータの操作）がある。
- 実装は、脳信号計測 → 脳情報解読 → デバイス操作 → フィードバック。脳計測には、安全性と脳の情報量の
  トレードオフがある（侵襲型は情報量が多いが危険、非侵襲型は安全だが情報量が少ない）。
- 運動想像パラダイム：想像した体の部位によって、脳波の振動成分が変わる。mu 波（8〜12 Hz）と
  beta 波（15〜30 Hz）が減衰する（ERD）。右手なら左側のセンサ、左手なら右側のセンサが反応する。
- 活動する周波数・位置・強さは人によって違う。だから個人ごとに判別ルールを学習する必要があり、
  キャリブレーション実験で最初にサンプルを取る。
- 運動想像型の問題点：使いこなせる人が限られる。長期訓練が必要。想像は外から見えないので、
  システムのデバッグが難しい。
- その他の実際的な問題：計測準備の手間、キャリブレーションの時間、アーチファクト
  （体動・眼球運動・筋電。独立成分分析などで対処）。
- 他に刺激誘発型（P300、定常視覚刺激）の説明、ATR の EEG-NIRS 同時計測の研究、倫理の話もある。

#### アルファ波BCI_新潟大学堀研.pdf

- α波（8〜13 Hz）は安静時に出て、興奮すると周期性を失う（α波阻止）。これを使って「意思」の
  ON/OFF を検出する BCI を作った。
- 処理：多チャンネルの脳波 → 8〜13 Hz のバンドパス → 絶対値 → 包絡 → 出力。複数チャンネルの出力を
  論理積・論理和・排他的論理和で組み合わせて確度を上げる。
- 実験：20代の健常男性5名、国際10-20法の電極、サンプリング 1 kHz、5次バンドパス 8〜13 Hz。
- 結果：電極（チャンネル）の数を増やすほど確度が上がった。最高確度は 88.7%。
  8〜13 Hz の帯域が有効だった。β 波帯域（30〜50 Hz 付近）でも変化は見られた。
- 想像の仕方によって、α波阻止が起きる区間が変わった。

#### ERDを用いたBCI提案_和歌山大学2017.pdf

- 学生プロジェクトの成果報告書（4ページ）。ERD は特定の波形ではなく振幅の減衰を見るので、
  加算平均などのノイズ除去なしで判別でき、処理が速い、という理由で ERD を選んだ。
- 目標は、α波帯域とβ波帯域の両方の ERD を併用して精度を上げること。
- 実験：被験者3名が、つま先を上げる運動を23回想起。フーリエ変換で α 帯と β 帯に分け、
  変化率 = (想起測定値 − 基準値) / 基準値 × 100 が −10% 以下なら ERD ありと判別。
- 結果：ERD の平均検知率は α 帯 52.8%、β 帯 22.2%。両帯域の相関係数は r = 0.1370。
  目標は達成できなかった。
- この報告書は成功した研究ではない。被験者3名で、数値の根拠としては弱い。

#### 資料ごとの周波数帯の違い

| 資料 | mu / α | beta |
|---|---|---|
| Bonci（英語チュートリアル） | 8〜15 Hz | 10〜30 Hz |
| ATR 講義 | 8〜12 Hz | 15〜30 Hz |
| 新潟大学 | 8〜13 Hz | 30〜50 Hz 付近でも変化 |

資料によって境界は少しずつ違い、周波数は人によっても違う。このリポジトリの `L_FREQ = 8.0`、
`H_FREQ = 30.0`（`src/tpv/preprocessing.py`）は、上の3つの資料の mu / α から beta までを
ほぼカバーする範囲。Bonci の図 11 も 8〜30 Hz のバンドパスを使っている。

### メモ：波の名前は周波数で決まる

- 脳波は、いろいろな周波数の振動が混ざった1本の信号。その中の周波数の範囲に名前が付いている
  （α / mu 波は 8〜13 Hz あたり、β波は 13〜30 Hz あたり）。波の強弱で名前が変わるわけではない。
- 同じ周波数帯の中で、強さ（パワー、振幅）が時間とともに変わる。運動イメージで mu / beta 帯のパワーが
  下がるのが ERD。
- 周波数成分はどの電極にも入っている。違うのは、ある周波数帯の強さが、いつ・どの場所で変わるか
  （運動イメージの ERD は運動野付近の電極で出る）。
- 周波数帯の境界は資料ごとに少し違う（上の表）。決まった境界ではなく、慣習的な区切り。
- 脳波の振動が何から生まれるか（神経細胞の同期活動など）は、`reference/` の資料では確認していない。

## AI の利用

このプロジェクトでは AI（Claude Code）を使った。使い方は次の3つ。

| 用途 | 内容 |
|---|---|
| コードの補助 | コードの意味の確認（例：`filter_raw` が何をしているか）。 |
| リファレンスの提示 | 参考になる日本語・英語の資料（PDF、論文、公式チュートリアル）をネットで探してもらった。`reference/` の PDF の名前の整理もした。 |
| 解説 | 脳波・運動イメージ・ERD・CSP・データセットの run の構成などの説明。`reference/` の PDF を読んでもらって、「各 PDF の要点」にまとめた。 |

注意：

- AI の説明には、AI の一般知識から出たもの（資料の裏付けがないもの）が含まれる。
  根拠は「参考」の資料で確認すること。
- AI のネット検索は、検索結果の要約を読んだだけのことがある。リンク先の中身まで確認したものばかりではない。
- 「各 PDF の要点」は AI が PDF を読んでまとめたもの。数値や用語は元の PDF で確かめること。
